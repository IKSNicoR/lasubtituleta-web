Adobe Premiere no entiende español, pero nosotros necesitamos los subtítulos.

La Subtituleta es una extensión GRATIS para Windows y Mac que transcribe en español con IA y deja los captions listos en tu timeline.

Gratis · Sin suscripción · Usás tu propia API

Hecha por un editor cansado de corregir subtítulos.

  • 01

    Entiende lo que Premiere no se molesta en entender

    Siglas, términos técnicos, voseo y nombres propios. Menos correcciones a mano.

  • 02

    Captions nativos, cortados como editor

    Los editás como siempre. Con Reflow Lines reordenás las líneas para otro formato en segundos.

  • 03

    Sabe quién habla

    Identifica a cada hablante, ideal para entrevistas, programas y varias voces.

  • 04

    Data para tu IA

    Genera data con la que Claude o ChatGPT pueden trabajar. El JSON trae metadata para que tu IA arme clips, con menos tokens que subir el video.
