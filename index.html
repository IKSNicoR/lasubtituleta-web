Se instala en 3 pasos.

Sin cuenta en La Subtituleta. Instalás, pegás tu API key y listo.

Windows Mac

  1. Bajá y descomprimí.

    Cerrá Premiere, descargá el ZIP y descomprimilo por completo.

  2. Ejecutá el instalador.

    Doble clic en INSTALAR.cmd.

  3. Abrí Premiere y pegá tu API key.

    Ventana > Extensiones (heredado) > La Subtituleta. Tocá el engranaje, pegá una API key y guardá.

Descargar para Windows

Necesitás Premiere Pro 2024 o posterior. Todavía no tiene la firma de Apple, así que macOS te va a pedir una confirmación extra. Es normal.

  1. Bajá y descomprimí.

    Cerrá Premiere (Cmd+Q), descargá el ZIP y hacé doble clic para descomprimirlo.

  2. Ejecutá el instalador.

    Doble clic en INSTALAR.command. Si macOS lo bloquea: Configuración del Sistema > Privacidad y seguridad > Abrir igualmente. No hace falta contraseña ni instalar nada más.

  3. Abrí Premiere y pegá tu API key.

    Ventana > Extensiones (heredado) > La Subtituleta. Tocá el engranaje, pegá una API key y guardá.

Descargar para Mac
Si algo falla
macOS bloquea el instalador
Entrá en Configuración del Sistema > Privacidad y seguridad > Abrir igualmente. En versiones anteriores de macOS puede alcanzar con clic derecho sobre INSTALAR.command > Abrir. No desactives la seguridad global de la Mac.
Dice que no tenés permisos
Abrí Terminal, escribí /bin/bash seguido de un espacio, arrastrá INSTALAR.command desde Finder a esa ventana y presioná Enter. No escribas la ruta a mano ni uses sudo.
No aparece en el menú
Cerrá y reabrí Premiere por completo. Si sigue sin aparecer, reiniciá la Mac.

No pide contraseña de administrador ni instalar Python o Node.
