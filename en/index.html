Install it in 3 steps.

No account on La Subtituleta. Install it, paste your API key, done.

Windows Mac

  1. Download and unzip.

    Close Premiere, download the ZIP and extract it completely.

  2. Run the installer.

    Double-click INSTALAR.cmd.

  3. Open Premiere and paste your API key.

    Window > Extensions (Legacy) > La Subtituleta. Click the gear icon, paste an API key and save.

Download for Windows

You need Premiere Pro 2024 or later. The app isn't signed by Apple yet, so macOS will ask you for an extra confirmation. That's normal.

  1. Download and unzip.

    Quit Premiere (Cmd+Q), download the ZIP and double-click it to extract.

  2. Run the installer.

    Double-click INSTALAR.command. If macOS blocks it: System Settings > Privacy & Security > Open Anyway. No admin password and nothing else to install.

  3. Open Premiere and paste your API key.

    Window > Extensions (Legacy) > La Subtituleta. Click the gear icon, paste an API key and save.

Download for Mac
If something goes wrong
macOS blocks the installer
Go to System Settings > Privacy & Security > Open Anyway. On older macOS versions, right-clicking INSTALAR.command > Open may be enough. Don't turn off your Mac's global security.
It says you don't have permission
Open Terminal, type /bin/bash followed by a space, drag INSTALAR.command from Finder into that window and press Enter. Don't type the path by hand or use sudo.
It doesn't show up in the menu
Fully close and reopen Premiere. If it still doesn't show up, restart your Mac.

It doesn't ask for an admin password or require Python or Node.
